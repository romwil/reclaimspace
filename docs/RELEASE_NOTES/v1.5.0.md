## Reclaimspace v1.5.0

Leftover movie and TV folders can be reviewed on the Media page. A folder is listed only when it is missing from both the manager and Plex. Duplicate scans still never delete files.

### Highlights

- **Missing from both sides** — a top-level movie folder is a candidate only when Radarr and Plex do not have it. A TV folder is a candidate only when Sonarr and Plex do not have it. A folder either one still has stays on disk
- **Quarantine first** — the folders you choose move into the existing media quarantine folder. Loose files sitting in the library folder stay where they are
- **Restore will not overwrite** — if the original name is already there, that folder stays in quarantine and the page says so
- **Purge is only these folders** — Purge deletes the orphan-folder quarantine entries you confirm. It does not delete duplicate-file quarantine

### Added

- **Orphan folders** on the Media page runs in the background for Movies or TV and lists candidates largest first
- If Radarr, Sonarr, or Plex cannot be read, the scan stops and lists nothing
- **Quarantine** moves the named folders into the media quarantine root with kind `orphan_folder`
- **Restore** moves a folder back and stops when the original name is occupied. **Purge** permanently deletes only those orphan-folder entries
- Duplicate scans still never delete files

### Upgrade from v1.4.4

```bash
docker pull romwil/reclaimspace:1.5.0
```

Keep the existing config directory, reports, media mounts, appdata mount, and code mount. Recreate the container with the new image. Do not replace `settings.json`, and do not delete reports or the quarantine folder.

Open `http://your-server:8777/`. `/api/health` should report `1.5.0`. This release does not quarantine, restore, or purge anything by itself. **Orphan folders** runs only when you click it.
