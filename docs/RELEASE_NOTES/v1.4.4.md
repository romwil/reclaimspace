## Reclaimspace v1.4.4

**Remove empty folders** now clears a top-level appdata folder that has no files in it, even when the only things inside are empty subfolders. The page says how many folders were removed, including when that number is zero.

### Highlights

- **Empty means no files** — a top-level folder that contains only empty subfolders is removed. Those subfolders go with it
- **Mounted folders stay** — `_archive` and any folder a container still mounts are left alone, and the page says so when that is why nothing was removed
- **The result stays on the page** — you see the count, a read or delete error if one happens, and the scan list afterward. The button comes back when the action finishes or fails

### Fixed

- `POST /api/appdata/empty` returns `removed`, `skipped_in_use`, and `errors`
- A symlink, socket, or pipe counts as content. Symlinks are not followed
- A failure on one folder is reported and does not hide a folder that was removed

### Upgrade from v1.4.3

```bash
docker pull romwil/reclaimspace:1.4.4
```

Keep the existing config directory, reports, media mounts, appdata mount, and code mount. Recreate the container with the new image. Do not replace `settings.json`, and do not delete reports or the appdata share.

Open `http://your-server:8777/appdata`. `/api/health` should report `1.4.4`. This release does not migrate, quarantine, delete, or purge anything by itself. **Remove empty folders** runs only when you click it.
