## Reclaimspace v1.3.0

The report grid now opens on the rows you can act on, and a merged Plex item can be split without moving any files.

### Highlights

- **Ready first** — the status filter opens on Ready, the groups that have something to quarantine
- **Protected count** — a chip for groups where every path is a current Radarr or Sonarr file, so nothing is safe to move
- **Every path** — expanding a row lists each Plex path, each protected path, and each candidate
- **Candidates** — the column counts files that would be quarantined, not every path on the item
- **Split in Plex** — on a row with two or more paths, separate them into individual library items. Confirm first; the prompt lists the full paths. Split does not move or delete files and does not change Radarr or Sonarr. It separates every file on that Plex item, including an intentional two-part movie. Afterward, run a new dry run — the open report does not update itself

### Added

- Split in Plex from the report grid (`POST /api/plex/split`, which calls `PUT /library/metadata/{ratingKey}/split` with the token in a header)
- `protected_count` on scan reports, job summaries, webhook text, and the grid chip. Older reports that omit the field still show the chip, counted from the groups
- Grid rows include the full `plex_paths`, `protected_paths`, and `candidate_paths` lists

### Changed

- Report grid status filter defaults to Ready
- Candidates column counts quarantine candidate paths only
- Protected groups are explained as every Plex path matching some current managed file. A merged item can list this title’s file and another title’s file; quarantine still skips the whole group

### Upgrade from v1.2.0

```bash
docker pull romwil/reclaimspace:1.3.0
```

Existing `config/settings.json`, media mounts, and quarantine data stay in place. Recreate the container with the new image; do not replace settings or delete the quarantine folder.

Open `http://your-server:8777/`, open a report, and confirm the grid starts on Ready, the Protected chip is present, and a multi-path row offers Split in Plex.
